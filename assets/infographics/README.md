# Exercise infographics (Arabic)

Full-page exercise infographics (Arabic labels, red target muscles, start/mid frames, steps, sets × reps).
Kept separate from `assets/anatomy/` because these are finished posters with text, not single-pose drawings.

Use for:
- Visual reference when generating new anatomy drawings (style, poses, muscle highlights)
- Background/B-roll frames or end cards in Arabic videos (Muscle Arabia channel)
- Thumbnail inspiration

Do not use them in English videos as-is (the text is Arabic). `catalog.json` lists each file with a description and muscle group.
