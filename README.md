# مصنع الفيديو — ZMAFIT

أتمتة كاملة **بتكلفة صفر** لإنتاج فيديوهات لياقة بدنية بالعربية ورفعها تلقائياً على يوتيوب.

```
GitHub Actions (مجاني)                          Make (اتصال يوتيوب الموجود)
┌──────────────────────────────┐                ┌──────────────────────────┐
│ 1. Gemini يكتب السكربت       │                │ 1. Webhook يستقبل الرابط │
│ 2. edge-tts تعليق صوتي عربي  │   ── Webhook ──▶│ 2. تحميل الفيديو         │
│ 3. Pexels لقطات مجانية       │                │ 3. رفع على يوتيوب        │
│ 4. ffmpeg مونتاج + ترجمة     │                │ 4. ضبط الصورة المصغرة    │
│ 5. GitHub Release            │                └──────────────────────────┘
└──────────────────────────────┘
```

## لماذا مجاني بالكامل؟

| المكوّن | الأداة | التكلفة |
|---|---|---|
| كتابة السكربت | Gemini API (الباقة المجانية) | 0 |
| التعليق الصوتي العربي | edge-tts (بدون مفتاح أصلاً) | 0 |
| اللقطات المرئية | Pexels API | 0 |
| المونتاج والترجمة | ffmpeg على سيرفر GitHub | 0 |
| الاستضافة والجدولة | GitHub Actions (بلا حدود للريبو العام) | 0 |
| الرفع على يوتيوب | Make (عمليتان لكل فيديو) | ~0 |

---

## التركيب — 6 خطوات

### 1) أنشئ ريبو على GitHub
اسم مقترح: `zmafit-video-factory`. **اجعله Public** — الريبو العام يمنحك دقائق تشغيل غير محدودة، وروابط تحميل مباشرة بدون توكن. لا يوجد أي مفتاح داخل الملفات (كلها في Secrets).

ارفع كل محتويات هذا المجلد إلى الريبو.

### 2) مفتاح Gemini (مجاني)
افتح <https://aistudio.google.com/apikey> واضغط **Create API key**.

### 3) مفتاح Pexels (مجاني)
<https://www.pexels.com/api/> — عندك مفتاح مستعمل أصلاً في سيناريو Make القديم، تقدر تعيد استعماله.

### 4) أضف الأسرار في GitHub
`Settings ← Secrets and variables ← Actions ← New repository secret`

| الاسم | القيمة |
|---|---|
| `GEMINI_API_KEY` | مفتاح Gemini |
| `PEXELS_API_KEY` | مفتاح Pexels |
| `MAKE_WEBHOOK` | رابط الويبهوك من Make (الخطوة 5) |

اختيارياً في تبويب **Variables**:

| الاسم | القيمة | الشرح |
|---|---|---|
| `TTS_VOICE` | `ar-EG-ShakirNeural` | الصوت |
| `TTS_RATE` | `+8%` | سرعة الإلقاء |

### 5) سيناريو Make
جاهز ومفعّل: **ZMAFIT — رفع فيديوهات المصنع على يوتيوب**.
انسخ رابط الويبهوك من الموديول الأول وضعه في `MAKE_WEBHOOK`.

### 6) التشغيل الأول
`Actions ← مصنع الفيديو — ZMAFIT ← Run workflow` واختر `shorts`.
المدة ~4 دقائق. الفيديو يُرفع **private** أولاً حتى تراجعه.

بعد ما تعجبك النتيجة، غيّر في `scripts/config.py`:

```python
YT_PRIVACY = os.environ.get("YT_PRIVACY", "public")
```

## الجدولة التلقائية

| اليوم | الساعة (الجزائر) | الصيغة |
|---|---|---|
| الإثنين / الأربعاء / الجمعة | 10:00 | شورتس عمودي 9:16 |
| الأحد | 10:00 | فيديو أفقي 16:9 (~4 دقائق) |

للتعديل: غيّر سطور `cron` في `.github/workflows/video.yml` (بتوقيت UTC = توقيت الجزائر ناقص ساعة).

## المواضيع

`topics/queue.txt` — سطر واحد لكل موضوع. المصنع يأخذ السطر الأول، ينتجه، وينقله إلى `topics/done.txt`.
فيه 40 موضوعاً جاهزاً = 3 أشهر من المحتوى. أضف مواضيعك في أي وقت.

لإنتاج موضوع محدد فوراً: `Run workflow` واكتب الموضوع في خانة `topic`.

---

## الموسيقى الخلفية (اختياري)

ضع ملفات `mp3` خالية من الحقوق في `assets/music/`.
المصنع يختار مقطعاً عشوائياً ويخفض صوته تلقائياً تحت التعليق الصوتي (ducking).
إذا كان المجلد فارغاً يشتغل بالتعليق الصوتي وحده.

مصادر مجانية: Pixabay Music، YouTube Audio Library، Free Music Archive.

## التخصيص السريع

كل شيء في `scripts/config.py`:

| الإعداد | الشرح |
|---|---|
| `VOICE` | الصوت العربي — جرّب `ar-SA-HamedNeural` أو `ar-DZ-IsmaelNeural` |
| `VOICE_RATE` | سرعة الإلقاء |
| `MUSIC_VOLUME_DB` | مستوى الموسيقى (-21 افتراضياً) |
| `FORMATS[...]["target_seconds"]` | المدة المستهدفة |
| `FORMATS[...]["scenes"]` | عدد المشاهد |
| `SUB_HIGHLIGHT` | لون تمييز الترجمة (بصيغة BGR) |
| `YT_PRIVACY` | `private` / `unlisted` / `public` |

## التشغيل المحلي (للتجربة)

```bash
pip install edge-tts
export GEMINI_API_KEY=...
export PEXELS_API_KEY=...
python scripts/main.py --format shorts --topic "تمارين البطن في البيت"
```

النتيجة في مجلد `out/`.
